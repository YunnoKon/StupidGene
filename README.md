# Stupid Gene
**Stupid Gene** is a *stupid* TS library written by myself to play with evolutionary algorithm. It currently consist almost nothing but there are some examples for you to play with!

## Examples
- **Genetic Algorithms**
    - [Random String](./example/randStr.ts)
    - [Number Optimization](./example//numOptimize.ts)
- **Evolution Strategies**
    - [Peak Value](./example/peakValue.ts)

## Download
Currently the project is only avaliable in Github.

To download through `npm`, use the `npm` branch
```bash
npm i https://github.com/YunnoKon/StupidGene/tree/npm
```
